# خطوة (Khatwa) — نسخة بايثون

تطبيق يساعد على كسر العجز المتعلم بخطوات صغيرة (٢-٥ دقايق) ومراجعة الأفكار بواقعية، مكتوب بـ Python وإطار [Flet](https://flet.dev) ويشتغل على أندرويد وآيفون. البيانات كلها محلية على الجهاز (ملف JSON)، بدون حساب ولا سيرفر.

## الشاشات
البداية، اليوم (خطوة اليوم + الأسبوع)، مفكرة الأفكار (٣ أسئلة)، الإنجازات، المزاج والطاقة، والإعدادات (تذكير يومي، وضع اليوم الثقيل).

## التشغيل محليًا
```bash
pip install "flet>=1.1.2" "flet-notifications>=1.1.2" "flet-cli>=1.1.2" "flet-desktop>=1.1.2" pytest
cd src && flet run main.py
```

## الاختبارات
```bash
python -m pytest -q
```
- `tests/test_store.py`: منطق التخزين والمهام والأسبوع (بدون Flet).
- `tests/test_ui.py`: يبني كل الشاشات ويجرب الإجراءات والتذكير بدون تشغيل Flet فعلي. يتخطى نفسه إذا flet مو مثبت.

## البناء (GitHub Actions)
`.github/workflows/build.yml`: يشغّل الاختبارات، ثم يبني APK ويرفعه (Actions ← آخر تشغيل ← Artifacts ← khatwa-apk). بناء iOS (محاكي) يدوي من **Run workflow**.
بناء آيفون حقيقي يحتاج توقيع؛ انظر أسفل.

## التذكير اليومي
- يستخدم `flet-notifications`: إشعار واحد باليوم، يتجدول من جديد كل فتحة للتطبيق.
- صلاحية الإشعارات تنطلب لما المستخدم يشغّل التذكير. لو رفضها يبقى مطفي ويطلع له تنبيه.
- **ما انجرّب على جهاز حقيقي بعد.** جرّبه على جوالك: فعّل التذكير، اختر وقتًا بعد دقيقتين، وأغلق التطبيق.

## البنية
```
src/main.py     الواجهة (Flet 1.x) والتذكير
src/store.py    الحالة والتخزين (بايثون صرف)
src/tasks.py    نصوص المهام الصغيرة والمهام الأخف
tests/          اختبارات المنطق والواجهة
```

## مبادئ التصميم
- ما فيه عقوبات ولا "كسرت السلسلة": الأسبوع يعرض الأيام اللي سويت فيها شي فقط.
- "مو اليوم؟ خذ خطوة أخف" يعطي مهمة أسهل بدون لوم ولا إنجاز وهمي.
- التطبيق أداة دعم وعادات يومية وما يغني عن مختص (مكتوب داخل التطبيق).

## ملاحظة عن تاريخ الملفات
`src/main.py` و`src/store.py` و`src/tasks.py` انكتب فوقها بالغلط ثم أُعيدت كتابتها. `store.py` و`tasks.py` مطابقة للأصل (تحققنا بمقارنة سلوكها مع الـ bytecode الأصلي). `main.py` كتابة جديدة بنفس الشاشات والنصوص والألوان، مو نسخة حرفية.
